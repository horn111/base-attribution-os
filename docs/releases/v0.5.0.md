# Base Attribution OS v0.5.0 Release Brief

Status: release candidate

## Product boundary

The v0.5.0 release train extends Attribution Proof Loop with static Proof Sets:

- `@base-attribution-os/core` validates, normalizes, deduplicates, and aggregates replay reports;
- `bao proof-set` emits canonical JSON manifests or calldata-free Markdown summaries;
- the Observatory publishes explicitly registered BAO and Stack the Bag evidence;
- proof pages show set-level coverage, replay progress, network totals, and unique transactions.

One Proof Set belongs to one Builder Code and may span multiple Base networks.
The feature does not add hosted ingestion, storage, telemetry, runtime RPC calls,
new scanner rules, or GitHub Action inputs.

## Public contract

Core adds `AttributionProofSet`, `AttributionProofSetSummary`,
`CreateAttributionProofSetOptions`, `createAttributionProofSet()` and
`parseAttributionProofSet()`. Manifests use `schemaVersion: 1`, accept at most
100 reports and 10,000 unique transactions, and identify evidence by chain ID
plus lowercase transaction hash.

CLI adds `bao proof-set`, `proofSetCommand`, `ProofSetOptions` and
`ProofSetFormat`. Existing `proof`, `replay`, scanner, adapter, and Action
interfaces remain compatible.

## Gates

- Node.js 20 and pnpm 9.15.4 pass the full release preflight and eight-package external smoke.
- Hostile manifests, corrupted counters, conflicting duplicates, invalid schemas, and oversized inputs fail deterministically.
- The committed Action bundle matches its source and the immutable `v0.5.0` ref produces SARIF.
- A clean Stack the Bag worktree passes generation, fail-closed probes, strict scanning, typecheck, tests, browser build, and standalone smoke with candidate tarballs.
- Candidate CLI reconfirms the existing direct batch-mint and Coinbase Smart Wallet/ERC-4337 Base Sepolia evidence.

Sponsored-call and USDC-payment paths remain disabled and do not block this
release. Full Stack logs remain private; only already-public transaction data
and a sanitized pilot summary may be committed or included in release notes.
