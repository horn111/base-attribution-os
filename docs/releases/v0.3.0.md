# Base Attribution OS v0.3.0 Release Brief

Status: published on 2026-08-28

## Product boundary

The v0.3.0 release train ships the merged attribution hardening baseline:

- Base Builder Code format and custom-registry chain ID validation;
- prototype-safe viem and ethers adapters;
- validated scanner configuration, stable fingerprints, rule-aware SARIF, and
  packed GitHub Action verification;
- public x402 seller, multi-file wallet, and Base mainnet calldata fixtures.

Project-level evidence tuning for additional monorepo layouts is deferred to a
later release.

## Stack the Bag pilot summary

The versioned candidate ran against Stack the Bag commit `2a793b6` without the
old CLI patch. The permanent integration merged at Stack the Bag commit
`d4ea6b99b49988eb62b669b56441a20ff5487ffb`. Its strict scan checked 176 source
files, found two transaction candidates, and returned zero findings.
Fail-closed probes rejected a missing Builder Code and an unattributed
`wallet_sendCalls` path.

TypeScript checks, 248 application tests, the production client build, the
immutable Action SARIF run, and the Stack production release gate passed. CLI
`0.2.1` rechecked the public Base Sepolia batch-mint and Coinbase Smart Wallet
transactions with `bc_4pe6m33m`; both passed, including the nested ERC-4337
UserOperation path.
