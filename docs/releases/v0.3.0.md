# Base Attribution OS v0.3.0 Release Brief

Status: versioned release candidate

## Product boundary

The v0.3.0 release train ships the merged attribution hardening baseline:

- Base Builder Code format and custom-registry chain ID validation;
- prototype-safe viem and ethers adapters;
- validated scanner configuration, stable fingerprints, rule-aware SARIF, and
  packed GitHub Action verification;
- public x402 seller, multi-file wallet, and Base mainnet calldata fixtures.

Project-level evidence tuning for additional monorepo layouts is deferred to a
later release.
