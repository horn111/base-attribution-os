# Base Attribution OS v0.3.0 Release Brief

Status: candidate qualified by the Stack the Bag pilot

## Product boundary

The v0.3.0 release train ships the merged attribution hardening baseline:

- Base Builder Code format and custom-registry chain ID validation;
- prototype-safe viem and ethers adapters;
- validated scanner configuration, stable fingerprints, rule-aware SARIF, and
  packed GitHub Action verification;
- public x402 seller, multi-file wallet, and Base mainnet calldata fixtures.

Project-level evidence tuning for additional monorepo layouts is deferred to a
later release.

## Gates

- The repository preflight and eight-package external-consumer smoke pass on
  Node.js 20 and pnpm 9.15.4.
- The committed GitHub Action bundle matches its TypeScript source.
- The Stack the Bag deep pilot passes strict scanning and verifies the existing
  direct batch-mint and Coinbase Smart Wallet ERC-4337 Base Sepolia evidence
  with the versioned candidate packages.
- Sponsored-call and USDC-payment paths remain disabled and do not block this
  BAO release.
- The immutable `v0.3.0` Action ref passes before the floating `v0` tag moves.

Full Stack the Bag pilot logs remain private. Release notes contain a sanitized
summary and only already-public transaction evidence.

## Stack the Bag pilot summary

The versioned candidate ran against Stack the Bag commit `2a793b6` without the
old CLI patch. The strict scan checked 167 source files, found two transaction
candidates, and returned zero findings. Fail-closed probes rejected a missing
Builder Code and an unattributed `wallet_sendCalls` path.

TypeScript checks, 227 application tests, and the production client build
passed. CLI `0.2.1` rechecked the public Base Sepolia batch-mint and Coinbase
Smart Wallet transactions with `bc_4pe6m33m`; both passed, including the nested
ERC-4337 UserOperation path.
