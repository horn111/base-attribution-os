# Base Attribution OS v0.4.0 Release Brief

Status: release candidate

## Product boundary

The v0.4.0 release train adds a bounded monorepo evidence graph to Attribution Doctor:

- workspace discovery from npm/pnpm manifests and optional `bao.config.json` overrides;
- relative, tsconfig path, workspace package, package export, and re-export resolution;
- strict evidence links for viem, wagmi, ethers, wallet, Privy, x402, agent, and raw RPC paths;
- dependency-aware `--changed-since` scans that include affected providers and consumers;
- the hardening fixes already recorded in the two pending patch Changesets.

The resolver does not traverse external `node_modules`, execute bundler plugins, or perform runtime module resolution. Core and adapter runtime APIs do not change. The additive `BaoWorkspaceConfig` scanner type mirrors the JSON configuration.
